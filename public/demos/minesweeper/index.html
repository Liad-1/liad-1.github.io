Minesweeper (Python)

A JavaScript port of the original Python + pygame game, using its sprites, font and rules.

Left-click to reveal a cell, right-click to flag it. The smiley starts a new game, the gear opens the settings (click it again to save; the game restarts), and Esc pauses. AUTO SOLVER is still a work in progress: it makes the first move and then hands back to you (click the face to play).
